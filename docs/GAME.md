# 读谱游戏

本地地址：`http://127.0.0.1:4317/game.html`。首页提供入口；旧 `game-demo.html` 地址继续可用。构建将同一个游戏页面打包到两个地址，曲谱直接来自现有曲库，不维护另一份音符数据。

## 当前玩法

- 默认左右各半：左侧指板，右侧上 2/3 为谱面、下 1/3 为四弦拉弓区。底部只显示当前指法与音名；分数与记录在结果或记录面板查看。设置集中在右上角，不在右下显示拉弓指导文字。
- 琴头朝右，四根弦从上到下为 A、D、G、C；指序从左到右为 4、3、2、1，分别对应小拇指、无名指、中指、食指。弦距加大；图示不是真实琴上的距离尺。
- 左手按指仅准备音高，不触发声音或判题。3 指音必须同时按住同弦 1、2、3 指，4 指音按住 1～4 指；拉弓时缺少前置手指会提示补齐，不提交该音。
- 右手按下对应 A / D / G / C 弦道时发音和判题。读取该弦当前左手状态；没有落指即为空弦，不设左手空弦按钮。另一根弦上按着手指不影响当前弦发音。
- 连续同音可保持左手不动，右手松开后再次拉弓。抬起高指可以准备较低音，只有下一次拉弓才提交。长音只需一次拉弓，休止无需操作。
- 手机使用独立触点；PC 在设置选择左手琴弦后，用数字 1～4 按住指位，空格拉所选弦；A / S / D / F 分别直接拉 A / D / G / C 弦。数字 0 已不参与空弦操作。按键重复不连续提交，输入框与弹窗内不截获快捷键。
- 暂停、重练、后台或窗口失焦会清空左右手触点。打开设置或练习记录会暂停；关闭后手动继续。
- 第一把位为默认固定手型；切换把位会更新指板。无法覆盖整曲时禁止开始。暂不支持曲中自动换把、伸张和半把位。
- 等音判断包含八度。不同弦上同音高的位置均可作答。
- 当前开放小星星主题、风之歌、D 大调上行、C 大调音阶，按录入小节顺序走一遍，不展开反复。
- 「等你答对」会在音符到判定线时等待；「持续走谱」记录漏音。节奏窗口为提前 320 毫秒至延后 380 毫秒，按右手拉弓时刻计算，不含左手准备时间；认谱模式不评节奏。
- 提示会显示完整指法组合和可用弦道；空弦只提示弦道。提示或音名辅助标记为辅助完成，不计入独立首次答对。

## 记录和适配

`cello-game-records-v1` 独立保存每轮完成记录，不改写原有曲目与读谱反应记录。记录面板显示最近 20 轮，JSON 导出包含全部记录；暂不支持导入。浏览器存储不可用时会报告未保存。

首次使用本版默认设计图的左右分区；设置中保留上下布局并记忆选择。旧版布局偏好不会覆盖本次新默认。速度与音名辅助偏好继续保留。安全区域、动态视口、全屏入口已处理；已检查 844×390 模拟横屏，页面不横向溢出。iPhone / Android 的真实多指触感、音频与浏览器工具栏仍需真机验收。

## 维护

- `src/game-demo.html`：页面、输入、移动谱带、记录与偏好。
- `src/game-core.js`：游戏指位音高、同音判断、节奏窗口、状态统计。
- `tests/game.test.cjs`：独立预期音高、同音异弦、八度拒绝、休止、窗口边界、提示统计，以及真实页面事件处理的多点触控、空弦拉弓、连续同音、按键重复抑制与清理。
- `scripts/build.cjs`：将共用曲库和游戏逻辑嵌入独立 HTML。

运行 `npm test`、`npm run build`，再从首页检查入口和两种布局。游戏目前的半音四指手型与旧「指板探索」模块的手型配置不同，修改其中一处不要直接覆盖另一处；后续统一需先核对两种教学含义与既有页面行为。
