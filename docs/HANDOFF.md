可直接给新电脑上的 Codex 这段话：

> 这是我的大提琴练习册项目。请先读取 AGENTS.md、docs/HANDOFF.md 和 docs/DEVELOPMENT.md，检查 Git 状态，并核对已有功能。保留显示辅助、隐藏简谱、iPhone 播放兼容和已有曲目。不要删除文件或覆盖未提交改动。接下来我要修改的是：〔在这里填写〕。

原电脑的对话、临时文件、浏览器登录和 GitHub 凭据不会随 Git 克隆；本交接文件是跨电脑接续开发的入口。

## 用户背景与确定的产品约定

- 有大提琴老师，使用铃木第一册；开始项目时学习约 10 小时。网站用于跟随老师课程补充识谱与乐理。
- 主要自己使用，其他人可以公开访问。Windows / Mac 可继续开发，iPhone 可练习。
- 原有纸质教材和机械节拍器继续使用；取消单独空弦练习。
- 五线谱使用低音谱号。“显示辅助”打开音名、弦名、指法三个独立层；简谱另开关，默认隐藏。
- 页面没有 MusicXML 下载按钮，但仓库保存 XML，可导入 MuseScore。
- 练习记录只存在浏览器 localStorage，使用 JSON 导出/导入；不自动跨设备同步。
- 用户有已备案、个人主体的微信小程序，但本阶段没有改动或接入它。

## 架构与编辑位置

没有后端、数据库、构建框架或线上 API。数据与脚本通过构建器嵌入独立 HTML，字体也内嵌。

| 文件 | 职责 |
| --- | --- |
| `src/library.js` | 铃木、音阶数据；加载两个拓展曲目模块 |
| `src/laputa.js` / `src/advanced.js` | 两个天空之城版本的数据、辅助指法和乐理内容 |
| `src/core.js` | 音高、拍数和结构校验、播放路线、延音合并、记录备份合并 |
| `src/notation.js` | SVG 与 MusicXML；临时记号、三连音、连线、反复和辅助层 |
| `src/app.js` | 交互、Web Audio、播放高亮、记录、打印分页 |
| `src/index.html` / `src/styles.css` | 页面骨架与样式 |
| `scripts/build.cjs` | 内嵌模块并写入 dist；生成每课练习/辅助两份 XML |
| `dist/scores/` | 28 份 XML、14 份预生成 PDF；进阶版 PDF 为 26 页 |

音符事件的 `beats` 是实际四分音符拍数；三连音使用 `beats=2/3`、`writtenBeats=1` 和 `tuplet` 元数据。MusicXML 普通曲目 divisions=8，进阶谱为 24。连弓端点采用一基小节号、零基音符索引；播放内部 `bar` / `index` 均零基。弱起曲目的数组索引与印刷小节号不同，显示必须用 `barLabel`。

## 验证状态与边界

交接时另用全新 Git 克隆验证：无需安装应用依赖，`npm test` 22 项通过，`npm run build` 生成 14 个条目，构建后 Git 工作区无差异。此验证在 Windows 完成，未宣称 Mac 已实测。

截至核对日期，22 项核心测试通过，28 份 XML 通过 MusicXML 4.0 Schema 校验；桌面 Edge、390px 手机视口、音频调度、备份、打印和线上文件一致性已检查。没有真实 Mac 或 MuseScore 界面验收。用户曾在真实 iPhone 上确认关闭静音后能发声；之后代码加入 audioSession 播放类别兼容，不能把模拟手机视口测试等同于真实 iPhone 验证。

Web Audio 是合成参考音，不模拟真实大提琴音色与完整运弓。没有离线 Service Worker；首次访问或重新打开网站不保证无网可用。

## 没有随仓库同步的东西

- 原始铃木 PDF 和天空之城谱图：用户私有资料，保留在原电脑下载/临时目录，未公开发布。所有转录音符已在 src 中，构建不依赖原图；重新逐音核对时需用户另行提供。临时目录不可靠，原件宜另存私人备份。
- 浏览器中的个人练习记录：请在网页“练习记录”导出 JSON，再在目标浏览器导入。Git 同步代码不会同步记录。
- GitHub 登录凭据：新电脑自行登录；不复制或提交 token。
- qa 截图、临时 PDF 备份、ZIP：被 Git 忽略，可按开发文档重新生成。

没有已知的阻塞开发问题。换把指法与演奏适合度仍由老师确认；微信小程序、云端记录同步和离线缓存尚未实施，不能当作已有功能。
