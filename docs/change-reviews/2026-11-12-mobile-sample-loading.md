# 手机网页音色加载与发声排查

- 网页基线 `b3d3f57`，小程序基线 `864c6d4`。用户反馈手机网页练习曲无声，尚未获得手机端错误日志，不能将桌面复现等同于已确定手机根因。
- 线上录音包请求返回 200，大小 10,217,461 字节。发现录音准备等待没有整体时限、26 个录音并发解码，以及录音准备结束后未检查音频通道状态。
- 网页同步修改。录音下载和解码等待上限为 8 秒，超时先使用已有合成参考音，后台录音准备完成后到下一次播放才启用。顺序解码限制峰值内存，练习曲在录音准备后重新检查并恢复音频通道。加载状态移到播放控制区。
- 小程序结论为平台专属无需同步。小程序使用包内 ADPCM 数据和原生 PCM 播放，未使用网页脚本下载和 decodeAudioData 路径。
- 自动测试覆盖慢网、解码挂起、包缺失重试、并发请求共用任务和延后切换音色。WebKit 390px 下验证真实录音解码、渲染非零 PCM，以及人为在准备后暂停通道再恢复播放、暂停/继续/停止。
- 真机浏览器与网络情况仍待用户复测。网页发布以 GitHub Pages 部署状态和线上文件核对为准。
