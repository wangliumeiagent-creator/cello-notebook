这次练什么

    播放使用真人大提琴采样，用于核对音高与时值；录音加载失败时会提示并使用合成参考音。练琴时可以关闭网页节拍声，继续使用机械节拍器。

    三个数字，先分清楚

    谱上“弦 / 指”中的 Ⅰ–Ⅳ 依次代表 A、D、G、C 弦；0 是空弦，1–4 是左手手指。简谱 0 是休止，1–7 是音级；音名 D3 中的 3 表示八度（中央 C 为 C4）。
